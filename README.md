Entry for make.fun's "One Letter: Coffee or Tea" bounty. The program writes
exactly one letter to `/output/entry.txt`: **B** for tea.

Tea is the calm, ancient, refined ritual — steam over a quiet cup, patience
poured slowly, the honest drink of people who don't need to shout about
their mornings. One letter, nothing else.

Run with `python3 main.py` (or set `MAKEFUN_OUTPUT_DIR` to choose the
output directory).
